# らくばる君のリズム配達

落ちてくるチラシが青いポストに重なった瞬間にキーを押して配達する、音楽ゲームです。
曲は「らくばる」。ブラウザだけで遊べます（インストール不要）。

## 遊び方

| 操作 | パソコン | スマホ |
|---|---|---|
| 1〜4番目のポストに配る | `D` `F` `J` `K`（または `←` `↓` `↑` `→`） | 画面を左右4つに分けてタップ |
| スタート／もう一回 | `Enter` | 画面タップ |
| 一時停止 | `Esc` | — |
| むずかしさを選ぶ | `1` `2` `3` | 画面下のボタン |

- 判定は「ピッタリ！」「いいね！」「おしい」「ミス」の4段階。スコアは全部ピッタリで 1,000,000 点。
- ランクは S（95万点以上）／A／B／C／D。むずかしさごとのベストスコアがブラウザに保存されます。
- 押すタイミングがずれると感じたら「タイミング調整」で直せます（Bluetoothイヤホンは遅れやすい）。
- スマホは横向きにすると大きく表示されます。

## ファイルの構成

```
rhythm/
  index.html        画面の骨組み
  style.css         見た目
  game.js           ゲームの動きすべて
  charts.js         譜面（いつ・どのレーンにチラシが落ちるか）
  assets/
    rakubaru.png    らくばる君の画像
    rakubaru.mp3    曲「らくばる」
  tools/
    make_chart.py   曲を解析して charts.js を作るプログラム
```

## 自分のパソコンで動かす

`index.html` をダブルクリックで遊べます。
ただし、そのやり方だと音のずれ補正が少し粗くなるので、きっちり遊びたいときは公開ページ（GitHub Pages）か、
このフォルダで `python3 -m http.server` を実行して `http://localhost:8000/rhythm/` を開いてください。

## 改造してみよう

1. `game.js` の `JUDGES` の `win` を小さくすると判定が厳しくなります
2. `BASE_SPEED` を上げるとチラシが速く落ちてきます
3. `charts.js` の `[秒, レーン]` を書き足すと、自分で譜面を作れます

AIにこう頼んでみるのもおすすめです。

- 「長押しするチラシ（ホールドノーツ）を追加して」
- 「コンボが50を超えたら背景が朝焼けになるようにして」
- 「別の曲も選べるようにして」

### 譜面を作り直す（上級）

曲は BPM 156 として解析しています。`tools/make_chart.py` の数字（`thr` など）を変えて作り直せます。

```
pip install numpy scipy
ffmpeg -i assets/rakubaru.mp3 -ac 1 -ar 22050 song.wav
python3 tools/make_chart.py song.wav charts.js
```
