# らくばる君のポスティング大作戦

> 🎵 音楽ゲーム「[らくばる君のリズム配達](rhythm/)」も入っています（`rhythm/` フォルダ）。
> 🎆 シューティングゲーム「[らくばる君の花火大会](hanabi/)」も入っています（`hanabi/` フォルダ）。

らくばる君がスクーターで住宅街を走りながら、60秒でできるだけ多くのポストにチラシを配るブラウザゲームです。
パソコンでもスマホでも、ブラウザだけで遊べます（インストール不要）。

## 遊び方

| 操作 | パソコン | スマホ |
|---|---|---|
| 車線を変える | ↑ ↓ キー | ▲ ▼ ボタン |
| 前後に動く | ← → キー | ◀ ▶ ボタン |
| チラシを投げる | スペースキー | 「チラシを投げる」ボタン / 画面タップ |
| 音のオン・オフ | M キー | 右上の「音」ボタン |

- チラシは**真上**に飛びます。青いポストの真下で投げると配達成功。
- 続けて成功するとコンボで1軒あたりの点数が上がります。通り過ぎて配り残すとコンボが切れます。
- 「チラシ禁止」の貼り紙があるポストに入れるとクレームで −150点、さらに残り時間が1秒減ります。
- チラシは何枚でも投げられますが、ポストに入らず外れると残り時間が1秒減ります。
- コーンやネコにぶつかると残り時間が3秒減ります。

## らくばる君の花火大会（hanabi/）

下から上がってくる花火の玉が、画面上のスコープに入った瞬間にボタンを押すと花火が開きます。

- 操作：スペースキー（Enter・画面タップ・スマホの「ドン！」ボタンでも可）
- 中心に近いほど高得点（どんぴしゃ 300／うまい 200／おしい 100）、5コンボごとに倍率アップ（最大3倍）
- 虹色の玉は「らくばる君花火」。開くと夜空にらくばる君の顔が現れます（最大1500点）
- 玉の出るタイミング・速さはランダム。時間がたつと速くなり、ななめにも飛んできます
- `hanabi/game.js` の「1. 設定」で、制限時間・スコープの大きさ・らくばる君花火の出る確率などを変えられます

## 自分のパソコンで動かす

`index.html` をダブルクリックしてブラウザで開くだけで遊べます。

## 改造してみよう（練習課題）

`game.js` の一番上「1. 設定」の数字を変えるだけで、遊びやすさが変わります。

1. `GAME_TIME` を 90 にして、制限時間を90秒にする
2. `REFUSE_RATE` を 0.5 にして、禁止ポストを増やす
3. `START_SPEED` を上げて、スピード狂モードにする

慣れてきたら、AIにこう頼んでみてください。

- 「雨の日ステージを追加して」
- 「マンションの集合ポストを追加して、1回で3軒分配れるようにして」
- 「スコアランキングを表示して」
